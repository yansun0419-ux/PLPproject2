# Delphi Interpreter (Project 2)

## Overview
This project implements a Delphi/Turbo Pascal interpreter using ANTLR4 visitors.

The codebase keeps all Project 1 object-oriented features and adds the required Project 2 language features:
- while-do and for-do loops
- break and continue
- user-defined procedures and functions
- static scoping with scope chaining

## Implemented Features

### Project 1 Features
- Class declarations and object creation through constructors
- Destructors
- Encapsulation: PUBLIC / PRIVATE / PROTECTED / PUBLISHED handling
- Single inheritance
- Interface declarations and implementation checks
- Built-in ReadInt and WriteLn

### Project 2 Core Features
- while-do loops
- for-do loops (both TO and DOWNTO)
- break and continue control flow
- User-defined global procedures and functions
- Static scoping behavior

### Bonus Features
- Formal parameter passing in procedures/functions
- Simple constant folding for compile-time computable subexpressions
	- Example behavior: `v := 2*(10+11)` is folded to `v := 42`
	- Example behavior: `v := x + 2*3` is folded to `v := x+6`
	- The interpreter prints optimized assignment expressions with `[AST-OPT] ...`

## Static Scoping Rules Used
- A scope chain is maintained during interpretation.
- New scopes are created for compound blocks and loop bodies.
- Procedure/function calls always execute in a scope rooted at global scope, so caller local variables are not visible.
- Procedure/function local variables and formal parameters are visible in that call's local chain.

## Project Structure
- Grammar: src/main/antlr4/org/example/Delphi.g4
- Interpreter: src/main/java/org/example/DelphiInterpreter.java
- Test runner: src/main/java/org/example/Main.java
- Test programs: test_*.pas files in the project root

## Build and Run
Prerequisites:
- Java 17+ (or compatible newer JDK)
- Maven 3.6+

Commands:
```bash
mvn clean compile
mvn exec:java -Dexec.mainClass="org.example.Main"
```

## Notes
- This repository includes generated ANTLR artifacts in target/. They can be regenerated by Maven.
- The interpreter is intentionally focused on core assignment requirements and common Pascal patterns used by the provided tests.
